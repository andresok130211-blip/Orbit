# Orbit — голосовое управление Android

Голосовой ассистент для телефона: говоришь «Орбит, …» — он слушает, понимает команду и управляет телефоном через службу доступности Android.

## ИИ (Gemini)
Если команда не распознана правилами, Orbit спрашивает Gemini: тот понимает свободную речь, исправляет ошибки распознавания, строит цепочки действий («открой телеграм, найди Васю и напиши привет») и просто отвечает на вопросы. Переключатель «Всегда через Gemini» отправляет в ИИ каждую фразу.
1. Получи бесплатный ключ: https://aistudio.google.com/apikey
2. Вставь его в приложении и нажми «Сохранить ключ».

**Приватность:** в Gemini уходит фраза и короткий список видимых на экране элементов (поля паролей пропускаются). На бесплатном тарифе Google может использовать эти данные для улучшения своих продуктов. У бесплатного ключа есть лимиты запросов (при ошибке 429 подожди минуту).

## Локальная модель (без ключа, офлайн)
Orbit умеет запускать Gemma прямо на телефоне через MediaPipe LLM Inference.
1. Скачай модель формата MediaPipe `.task` (Gemma, на Hugging Face в разделе litert-community; нужно принять лицензию Gemma). Для 8 ГБ ОЗУ подойдут Gemma 3 1B (~0,5 ГБ, быстрее) или Gemma 3n E2B (~3 ГБ, умнее).
2. В приложении нажми «Выбрать локальную модель (.task)» и дождись копирования.
3. Если ключа Gemini нет, или облако недоступно (нет сети, лимит), Orbit автоматически использует локальную модель. Переключатель «Предпочитать локальную» включает её всегда.

Заметки: файл `.litertlm` (новый формат) этой версией не читается, нужен именно `.task`. Библиотека MediaPipe LLM Inference у Google в режиме поддержки, миграция на LiteRT-LM возможна позже. Первый ответ после запуска медленнее (загрузка модели в память).

## Что умеет
- открывать приложения, звонить по имени/номеру
- нажимать на кнопки и тексты на экране («Орбит, нажми отправить»)
- вводить текст в активное поле, прокручивать, свайпать
- назад / домой / недавние / шторка / скриншот / блокировка
- громкость, фонарик, будильник, таймер, поиск в интернете

Полный список команд виден в самом приложении.

## Сборка без Android Studio
1. Залей проект на GitHub (команды ниже).
2. Вкладка **Actions** → **Build APK** → дождись зелёной галочки.
3. В запуске скачай артефакт `orbit-debug-apk`, распакуй и поставь APK на телефон.

## Первый запуск
1. «Выдать разрешения» (микрофон, звонки, контакты, уведомления).
2. «Включить службу доступности» → Orbit → включить.
3. «Запустить Orbit» и говори: «Орбит, открой ютуб».

## Ограничения
- Распознавание речи — системное (Google), нужен интернет; при каждом цикле возможен короткий звук.
- Время для будильника лучше говорить цифрами («на 7:30»).
- Wi‑Fi и Bluetooth Android не даёт включать из приложений: открываются настройки, дальше «Орбит, нажми Wi‑Fi».
- Приложения с защитой экрана (банки) могут блокировать службу доступности.
